## 🌟 Key Highlights

- **Executive Aesthetic:** Dark-mode-first slate/obsidian palette (`#0B1120`), glassmorphic panels, and strict zero-vanity discipline (no filler charts or arbitrary percentages).
- **International Systems Delivery:** Documented client deployments across the **United Kingdom**, **Dubai (UAE)**, **India**, and **Pakistan**.
- **Interactive Technical Portfolio:** Multi-filter project showcase (`UK Clients`, `Dubai / UAE`, `LMS & EdTech`, `SaaS & APIs`, `E-Commerce & Business Systems`) with live portal links and deep architecture inspector modals.
- **AI-Assisted Engineering:** Showcasing disciplined adoption of Google Gemini and agent-augmented workflows under strict human architectural oversight.
- **Printable A4 CV / PDF Export:** Dedicated `@media print` styling that formats the application into an executive 1-to-2 page PDF resume via `window.print()`.

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/salmanzafar44/salman-zafar-portfolio.git
cd salman-zafar-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
